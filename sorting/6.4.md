## 6.4-2: Heapsort Invariant
<pre>
Pseudo Code
HEAPSORT(A, n)
    BUILD-MAX-HEAP(A, n)
    for i: n to 2
        exchange A[i] with A[1]
        A.heap_size = A.heap_size - 1
        MAX-HEAPIFY(A, 1)

Invariant
    At the start of each iteration of for loop of lines 2-5, the subarray A[1:i] is a max heap containing
    i smallest element of array A[1:n], and the subarray A[i+1:n] contains n-i largest elements of A[1:n], sorted.

Initiation
    At i = n, by virtue of the BUILD-MAX-HEAP propert, the subarray A[1:n] is a max heap, and the subarray A[n+1:n]
    is an empty array. Hence the invariance holds.
Maintenance
    We swap A[1] with A[i]. Now A[i] holds the maximum of A[1:i], placing it into its correct position 
    in the sorted region A[i:n]. We then decrement heap size to i - 1 and run MAX-HEAPIFY(A, 1) to restore
    the max-heap property for A[1:i - 1].
Termination
    At i = 2, subarray A[1:2] contains the smallest element of the array A[1:n], and the subarray A[3:n]
    contains the n-2 largest elements. The loop terminates.
</pre>
