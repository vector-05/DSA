# 7.3: Randomized QuickSort
## 7.3-1: Running Time
<pre>
We only evaluate expeted time complexity for randomized algorithms, as the chances of getting worst case input condition
with a randomized pivot are much smaller in larger datasets as opposed to deterministic algorithms
</pre>
## 7.3-2: Random Function Call
<pre>
We call the random function every once the randomized partition function is called. For both worst case and best case
it is called O(n) times.
</pre>
