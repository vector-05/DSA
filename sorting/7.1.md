# 7.1: QuickSort

## 7.1-1: Partition Function of QuickSort
<pre>
Partition Function of QuickSort Algorithm:
    PARTITION(A, p, r)
        x = A[r]
        i = p - 1
        for j:p to r - 1
            if A[j] <= x
                i = i + 1
                exchange A[i] and A[j]
        exchange A[i + 1] and A[r]
        return i + 1

Case Array, A = [2, 8, 7, 1, 3, 5, 6, 4]    (1 based indexing)
Initially, i = 0, p = j = 1, r = 8 => x = A[r] = 4
Iteration 1:
    j = 1
    A[j] = 2: Condition = True
        i = 1
        exchange A[1] and A[1]
    A = [2, 8, 7, 1, 3, 5, 6, 4]
Iteration 2:
    j = 2
    A[j] = 8: Condition = False
Iteration 3:
    j = 3
    A[j] = 7: Condition = False
Iteration 4:
    j = 4
    A[j] = 1: Condition = True
        i = 2
        exchange A[2] and A[4]
    A = [2, 1, 7, 8, 3, 5, 6, 4]
Iteration 5:
    j = 5
    A[j] = 3: Condition = True
        i = 3
        exchange A[3] and A[5]
    A = [2, 1, 3, 8, 7, 5, 6, 4]
Iteration 6:
    j = 6
    A[j] = 5: Condition = False
Iteration 7:
    j= 7
    A[j] = 6: Condition = False
Loop Terminates
Exchange A[r] and A[i + 1] => A[8] and A[4]
Hence, A = [2, 1, 3, 4, 7, 5, 6, 8]    (: Invariance Holds)
</pre>
## 7.1-2: Equal Elements Condition
<pre>
Consider array A = [a1, a2, a3...]
let a1 = a2 = a3 = ... = a
=> A = [a, a, a, ...] 
By virtue of the if condition in the for loop, the loop executes for all elements from 
j = 1 to j = r-1
This implies at the end of loop i = r - 1.
Hence the function returns the last element of the array or A[r] as i + 1 = r - 1 + 1 = r!
</pre>
