# 9.2: Randomized Select
## 9.2-2: Iterative Randomized Select
<pre>
Standard Randomized Select is given by
RANDOMIZED-SELECT(A, p, r, i)
    if p == r
        return A[p]
    q = RAMDOMIZED-PARTITION(A, p, r)
    k = q - p + 1
    if i == k
        return A[q]
    else if i < k
        return RANDOMIZED-SELECT(A, p, q-1, i)
    else
        return RANDOMIZED-SELECT(A, q+1, r, i-k)

RANDOMIZED-SELECT-ITERATIVE(A, p, r, i)
    while p < r
        if p == r
            return A[p]
        q = RANDOMIZED-PARTITION(A, p, r)
        k = q - p + 1
        if i == k
            return A[q]
            break
        else if i < k
            p = p
            r = q - 1
            i = i
        else
            p = q + 1
            r = r
            i = i - k
</pre>
