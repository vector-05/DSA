# 8.2: Count Sort
## 8.2-1: Count Sort Operation
<pre>
Count Sort Algorithm
COUNTING-SORT(A, n, k)
    let B[1:n] and C[0:k] be new arrays
    for i: o to k
        C[i] = 0
    for j: 1 to n
        C[A[j]] = C[A[j]] + 1
    for i: 1 to k
        C[i] = C[i] + C[i - 1]
    for j: n to 1
        B[C[A[j]]] = A[j]
        C[A[j]] = C[A[j]] - 1
    return B
    
Given Array
    A = [6, 0, 2, 0, 1, 3, 4, 6, 1, 3, 2], n = 11
    let k be 6 (max element of A)
    i.e. let C = [0, 0, 0, 0, 0, 0, 0]  (0 based indexing to account for 0 element)
    and B = []
    loop 2:
        C = [2, 2, 2, 2, 1, 0, 2]
    loop 3:
        C = [2, 4, 6, 8, 9, 9, 11]
    loop 4:
        B = [0, 0, 1, 1, 2, 2, 3, 3, 4, 6, 6]
Hence sorted array, B = [0, 0, 1, 1, 2, 2, 3, 3, 4, 6, 6]
</pre>
## 8.2-2: Stability of Count Sort
<pre>
Calculating positions in array C provides us with the last position of that element in sorted system, since the count of each element provides us with the high end of the element location, then we calculate array b, we subtract 1 from count to account for duplicates! Counting from n to 1 in final loop thus preserves the order of the elements as in input array as it encounters
the last element first and places it on the high end in sorted array. Counting from 1 to n simply reverses the order of similar
elementes in the sorted array.
</pre>
## 8.2-3: Revert Count for Stablility
<pre>
We can modify the algorithm such that for placing ith element in B array, we use the count of i-1 element and add 1 to it till the high end of ith element, this way we preserve the relative order while counting from i to n instead.
The new Pseudo Code can we written as

    COUNTING-SORT-FORWARD(A, n, k)
        let B[1:n] and C[0:k] be new arrays
        for i: o to k
            C[i] = 0
        for j: 1 to n
            C[A[j]] = C[A[j]] + 1
        for i: 1 to k
            C[i] = C[i] + C[i - 1]
        for j: 1 to n
            B[C[A[j] + 1]] = A[j]
            C[A[j]] = C[A[j]] + 1
        return B
</pre>
