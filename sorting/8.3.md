# 8.3: Radix Sort
## 8.3-1: Radix Sort Operation
<pre>
We have
    COW             SEA             TAB             BAR
    DOG             TEA             BAR             BIG
    SEA             MOB             EAR             BOAX
    RUG             TAB             TAR             COW
    ROW             DOG             SEA             DIG
    MOB             RUG             TEA             DOG
    BOX             DIG             DIG             EAR
    TAB             BIG             BIG             FOX
    BAR     -->     BAR     -->     DOG     -->     MOB
    EAR             EAR             MOB             NOW
    TAR             TAR             COW             ROW
    DIG             COW             ROW             RUG
    BIG             ROW             NOW             SEA
    TEA             NOW             BOX             TAB
    NOW             BOX             FOX             TAR
    FOX             FOX             RUG             TEA
</pre>
## 8.3-2: Comparison Sort Stabilty
<pre>
Insertion Sort: Stable
    Preserves reltive order while putting elements into subarray.
Merge Sort: Stable
    Combines subarray in same order of division, preserving relative order.
Heapsort: Unstable
    Heap/Binary Tree representation, on which we call the Max-Heapify function destroys the relative order.
Quicksort: Unstable
    Partition swaps can distort relative order by long distance passes

For any comparison sort to be stable in nature, we can use secondary indexing in same elements, whereby we sort same element by their secondary index of relative order, imitating radix sort from right to left.
</pre>
