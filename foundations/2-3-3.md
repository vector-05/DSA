# 2.3-3: Loop Invariant

## Code Snippet
<pre>
while i < n<sub>L</sub> and j < n<sub>R</sub>
    if L[i] <= R[j]
        A[k] = L[i]
        i = i + 1
    else A[k] = R[j]
        j = j + 1
    k = k + 1
</pre>

## Invariant
At the start of each iteration of the while loop, the subarray A[p...k - 1] contains the k - p smallest elements of L[1...n_1] and R[1...n_2], in sorted order. Furthermore, L[i] and R[j] are the smallest elements of their respective arrays that have not yet been copied back into A.

## Proof
### Initiation
Prior to the first iteration of the loop:
-   i = 1, j = 1, and k = p.
-   The subarray A[p...k - 1] = A[p...p - 1] is empty, containing k - p = 0 elements.
-   This empty subarray trivially holds the 0 smallest elements of L and R in sorted order.
-   Since i = 1 and j = 1, L[i] and R[j] are indeed the smallest uncopied elements of L and R.
-   Thus, the invariant holds initially.
