# 2.3-7: Modified Insertion Sort with Binary Search

## Time Complexity
<pre>
The time complexity of the insertion sort procedure is
    O(Insertion Sort) = O(Search) + O(Shift Operations)
as 
    O(Operation) = O(n^2)
even if binary search is used
    O(Search) = O(nlgn)
overall complexity
    O(Insertion Sort) = O(n^2) + O(nlgn)
    =>  O(n^2)
The overall complexity remains n^2 even if binary search is used.
