# Recursion Tree
## a: T(n) = T(n/2) + n<sup>3</sup>
<pre>
We have any recursion taking cn^3 time. Hence

                    T(n)
=>                  c(n)<sup>3</sup>
=>      c(n/2)<sup>3</sup>                c(n/2)<sup>3</sup>
=>  c(n/4)<sup>3</sup>    c(n/4)<sup>3</sup>    c(n/4)<sup>3</sup>    c(n/4)<sup>3</sup>
and so on ....
=>      O(1)    O(1)        O(1)        O(1) ....
By convention T(n) = O(1) for leaves

Height of the tree is
    log<sub>2</sub>n
At depth i we have subproblem size as
    n/2<sup>i</sup>
Number of nodes at depth i is
    2<sup>i</sup>

Time complexity at each level
    cn<sup>3</sup>
    2/8cn<sup>3</sup> = 1/4cn<sup>3</sup>
    4/64cn<sup>3</sup> = 1/16cn<sup>3</sup>
    and so on....

Cost of internal node at depth i is
    c(n/2<sup>i</sup>)<sup>3</sup>

Cost of all nodes at depth i is
    2<sup>i</sup>c(n/2<sup>i</sup>)<sup>3</sup>

Bottom level at depth = log<sub>2</sub>n has
    2<sup>log<sub>2</sub>n</sup> = n leaves

Adding costs at all levels
    T(n) = c(n)<sup>3</sup> + 2<sup>1</sup>c(n/2<sup>1</sup>)<sup>3</sup> + 2<sup>2</sup>c(n/2<sup>2</sup>)<sup>3</sup> + .... + 2<sup>log<sub>2</sub>n</sup>c(n/2<sup>log<sub>2</sub>n</sup>)<sup>3</sup> + O(n)

    this leads to the summation
        from i = 0 to log<sub>2</sub>n-1 of 2<sup>i</sup>c(n/4<sup>i</sup>)<sup>3</sup> + O(n)

    the summation is bound by 4/3 (using geometric series sumation)
    we get
        T(n) <= c(n)<sup>3</sup>(4/3) + O(n)
        since (n)<sup>3</sup> dominates
        =>  T(n) = O(n<sup>3</sup>)
