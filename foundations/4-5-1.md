# 4.5-1: Master Method

## a: T(n) = 2T(n/4) + O(1)
<pre>
We have a = 2, b = 4, and f(n) i.e. driving function as f(n) = O(1)
We see f(n) = O(n^(log base 4 (2-e))) when e = 1
giving f(n) = O(n^(log base 4 (1)))
=>     f(n) = O(n^0) = O(1)
Hence T(n) = O(n^(log base 4 (2))) = o(n^1/2)
</pre>

## Master Method Formula
### Case 1: Leaf Dominated 
<pre>
Condition 
    f(n) grows polynomially slower than n<sup>log<sub>b</sub>a</sup>
    f(n) = O(n<sup>log<sub>b</sub>a-e</sup>), for e>0
Solution
    T(n) = O(n<sup>log<sub>b</sub>a</sup>)
</pre>
### Case 2: Balanced 
<pre>
Condition 
    f(n) grows at the same rate as n<sup>log<sub>b</sub>a</sup>
    f(n) = O(n<sup>log<sub>b</sub>a-e</sup>log<sub>2</sub><sup>k</sup>n), for k>=0
    mostly k = 0
Solution
    T(n) = O(n<sup>log<sub>b</sub>a</sup>log<sub>2</sub><sup>k+1</sup>n)
</pre>
### Case 3: Root Dominated
<pre>
Condition 
    f(n) grows polynomically faster than n<sup>log<sub>b</sub>a</sup>
    f(n) = O(n<sup>log<sub>b</sub>a+e</sup>log<sub>2</sub><sup>k</sup>n), for k>=0
    mostly k = 0
Solution
    T(n) = O(f(n))
</pre>
