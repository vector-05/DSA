# 2.2-3: Average and Worst Case run time for linear search

## Worst Case: 
Key not in array - O(n<sup>2</sup>)
## Best Case: 
Key at pos 1 - O(1) or O(n)
## Average Case: 
Average checks required for element at i location is i. Hence
    Average Checks = Average of i summed over n = 1/n * n(n+1)/2 = n+1/2 - O(n)
