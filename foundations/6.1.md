# 6.1: Heaps
## 6.1-1
<pre>
Maximum Height:
    2^n elements at level n
    Assuming a full leaf level for maximum elements.
    Summing all nodes across all levels we get geometric summation of 2^k for k from 0 to h
    Hence maximum elements are 2^(h+1) - 1
Minimum Height:
    2^n elements at level n
    Assuming at least one node in leaf level for minimum elements.
    Summing all nodes across all levels we get geometric summation of 2^k for k from 0 to h-1
    Hence minimum elements are 2^(h) - 1,
    we add one element at leaf level, hence 2^h
</pre>
## 6.1-4
<pre>
In a max-heap, minimum element would be the rightmost element at bottom level (leaf).
</pre>
## 6.1-5
<pre>
The kth largest element woule reside between 1 and k-1 level
Lower Bound:
    Largest elements can exist as high up as the 1 level,
    As for k = 2, the largest element resides at level 1.
Upper Bound:
    In Max Heap, the leftmost element of any level is the maximum elemnt for that level,
    if all maximum elements reside of the leftmost brach of heap tree (upper bound condition)
    then kth maximum element resides at (k-1)th level.
</pre>
## 6.1-6
<pre>
For an array in sorted order
    [a1, a2, a3, ... , an]
    with, a1 < a2 < a3 < ... < an
Considering the Heap for this array we would get
            a1
        a2      a3
    ....    ...     ...
    we easily observe a minimum heap.
</pre>
